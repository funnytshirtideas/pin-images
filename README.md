# pin-images

Bild-Hosting fuer Pinterest-Pins (Amazon Merch Designs, Mockups).
Die Dateien werden ueber GitHub Pages ausgeliefert und als Media-URL in der
Pinterest-Bulk-CSV verwendet.

Namensschema: `{ASIN}_{slug}_{NN}.jpg`, 1000x1500.

Hier liegen ausschliesslich Bilddateien. Keine Zugangsdaten, keine CSVs.
